# RbnApp

rbnbilisim uygulamaları: Windows masaüstü araçları ve üretkenlik uygulamaları.

## Uygulamalar

- **[Desk Helper](https://github.com/RbnApp/desk-helper)**: WhatsApp, Telegram, Instagram, X, notlar ve dosyalar tek pencerede; sekmeli, bölünebilir panelli masaüstü çalışma alanı.
- **[SystemPro](https://github.com/RbnApp/SystemPro)**: Windows kurulum aracı: gereksizleri temizler, sistemi iyileştirir, sürücüleri günceller, temel uygulamaları tek tıkla kurar.
- **[Desk-Remote](https://github.com/RbnApp/desk-remote)**: Windows 10/11 için kendi sunucunda çalışan uzak masaüstü; Tailscale ağındaki sürekli açık bilgisayarlar için. Geliştirme aşamasında.
